# Security

Audiobook Maker runs on your own computer. It reads the chapter files you choose, writes the audiobook next to
them, and goes online only to download the voice models from Hugging Face the first time they're used.

If you find a security problem, please report it privately: on GitHub, open the **Security** tab of this repository
and click **Report a vulnerability**. Please don't open a public issue for it. You'll get a reply within two weeks.

Only the latest release gets fixes.
